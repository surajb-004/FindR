Security Policy

Reporting a Vulnerability

If you discover a security vulnerability in FindR, please report it privately to the project maintainers.

Include a description of the issue, the potential impact, and steps to reproduce it when possible.

Please avoid publicly sharing sensitive information or exploit details before the issue has been addressed.

Security Practices

- Use Firebase Authentication where authentication is required.
- Configure Firestore Security Rules to restrict unauthorized data access.
- Configure Storage Security Rules to protect uploaded files.
- Validate user input.
- Enforce appropriate permissions for administrative actions.
- Never commit private keys, service-account credentials, or other sensitive secrets.

Supported Versions

Security support depends on the current development status of the project.
